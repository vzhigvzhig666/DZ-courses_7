# Проверка приложения Wikipedia

Объект — приложение [Wikipedia от Wikimedia Foundation в Google Play](https://play.google.com/store/apps/details?id=org.wikipedia), пакет `org.wikipedia`

Прогон на Pixel 9 Pro XL с Android 15, версия приложения `50619-r-2026-11-18` из [официального APK Wikimedia](https://releases.wikimedia.org/mobile/android/wikipedia/stable/wikipedia-50619-r-2026-11-18.apk)

Тесты на Kotlin через Appium и UiAutomator2 проверяют пакет приложения и работают в контексте `NATIVE_APP`

| Экран | Что проверяется |
| --- | --- |
| Wikipedia languages | Заголовок, список, порядковый номер и код текущего языка, нажатие на его строку, кнопка добавления и возврат в Settings |
| Wikipedia languages с двумя языками | Добавленный Español, код ES, смена порядка перетаскиванием, меню удаления, выбор через флажок, выход из режима выбора, отмена и подтверждение удаления |
| Add a language | Заголовок, список с названиями языков, прокрутка, кнопка поиска, поле ввода, фильтр по Spanish, очистка запроса, состояние без результатов и кнопка Go back |

## Сценарии

1. Открыть список языков, перейти к добавлению языка, прокрутить список и вернуться в настройки
2. Найти Spanish, очистить запрос и проверить сообщение `No languages found` на несуществующий язык
3. Добавить Español, поменять порядок языков, проверить отмену удаления и убрать Español, чтобы в списке остался English

## Результат

`./gradlew androidTest` — 3 теста прошли, ошибок и пропусков нет
